# Implementation status

Updated 13 November 2026. Testnet runs: free challenges on
[`goal-4.proofee-anton.testnet`](https://testnet.nearblocks.io/address/goal-4.proofee-anton.testnet)
(step numbers like "4b" refer to [DEMO_RUN.md](DEMO_RUN.md)); bonded challenges on
[`goal-5.proofee-anton.testnet`](https://testnet.nearblocks.io/address/goal-5.proofee-anton.testnet)
([DEMO_RUN_TREASURY.md](DEMO_RUN_TREASURY.md)). Unit tests are in `contracts/goal/src/` (`lib.rs`,
`treasury.rs`, `math.rs`), sandbox tests in `contracts/goal/tests/integration.rs` and
`tests/treasury.rs` (real Bond Treasury wasm); `cargo test`: 117 unit + 3 integration + 6 Treasury
sandbox, green.

Statuses:
- **Testnet verified** — works on testnet, with a transaction;
- **Implemented** — in the contract and covered by tests, not run on testnet;
- **Simulated** — the demo imitates it;
- **Planned** — not built.
